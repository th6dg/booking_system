## Java concurrency real world
## Scenario
+ Simultaneous room bookings <br>
-> Multiple users try to book the same room at the same time.
+ Concurrent payment or invoice generation <br>
-> Parallel tasks updating user balance, generating receipts, sending emails...
+ Batch Operation <br>
-> cập nhật tình trạng phòng trống định kỳ hoặc gửi email xác nhận trong background thread.
